# UI direction (2026-10-03 redesign)

**Why:** the first UI looked like generic AI output (navy cards, blue pills, emoji chips, uniform rounded boxes).
**Skill note:** no skill named "impeccable" exists in the skill list or plugin catalog; `ui-ux-pro-max` (installed) was used. Its top
suggestion for this brief (pink/blue glassmorphism "Cinema Mobile" + a marketing hero) was rejected as wrong for a dense desktop tool; its
rules on density, no emoji icons, focus states, reduced motion and mono data type were kept.

**Principles**
- Warm charcoal (`#121110`), off-white text, hairlines instead of boxes, 3 px radius, system fonts only (offline tool: no web-font dependency).
- Colour carries meaning only: verdicts (green / ochre / red), the vermilion playhead and the record dot. Primary action = off-white fill.
- Mono for timecodes, scores, labels, metrics; sans for reading text.
- No emoji or glyph icons: status = coloured marker + word; icons = inline SVG sprite (`#i-play`, `#i-plus`, `#i-back`).
- Editor = editing-suite layout: video + inspector side by side, labelled B-ROLL / SPEECH timeline with ruler and playhead, underlined covered transcript lines.
- `prefers-reduced-motion` respected; `:focus-visible` ring everywhere; < 1000 px collapses to one column.

**Files:** `app/static/{index.html,style.css,app.js,editor.js}`. Every element id and JS behaviour is unchanged.
**Also fixed while reviewing screenshots:** one long hydrated film filled whole result pages (per-source cap: 4 in search, 3 per beat in planning) and the plan reused one source for most beats (sequence objective now penalises reusing a source, 0.03 per repeat).
