# Demo script (~5 min)

**Setup:** index built (curated Indian footage incl. planted "traps": a Delhi-signboard rain shot, an old 2019 flood clip, a sunny drone shot) · 2 past timelines imported into Edit Memory · NLE open · second laptop on the LAN.

| # | Show | Say |
|---|---|---|
| 1 | Thesis slide | "Every tool treats B-roll as search. Editors ask three other questions: **Is it true? Does it cut? Is it ours?**" |
| 2 | Hindi search `बारिश में सड़क पर ट्रैफिक` → variety clusters | "Base layer: shot-level search in Hindi, with relevant variety instead of 10 copies of one angle." |
| 3 | Script tab: paste the 5-line Mumbai monsoon script → **Plan** | "Now give it a script." |
| 4 | **TRUE:** red flag on the Delhi-signboard shot, with evidence; then the old 2019 clip with an auto "FILE · 2019" label | "This shot is relevant, but it's Delhi, from 2022. Exactly how out-of-context footage ends up on the news. We catch it *before* publishing." |
| 5 | **CUTS:** toggle "relevance-only" vs "cut-aware" and play both sequences | "Left: jump cut, a direction flip, an exposure jump. Right: wide → close, motion flows. We optimise the *sequence*, not single shots." |
| 6 | **YOURS:** toggle Edit Memory on/off; ranking changes; show "chosen 4× in your past edits" + house style ("you open with aerials") | "It learned from this editor's two past projects. Zero labelling." |
| 7 | Export → open in Premiere/Resolve; the FILE label shows as a title | "It lands on the timeline, honest by default." |
| 8 | Benchmark slide: Indic Query Set + Contradiction Set results | "We built our own benchmark; here are the numbers." |
| 9 | Second laptop + roadmap | "Offline, CPU-only, LAN for teams. Next: audit mode for newsrooms, broadcaster archives." |

## Sample script
```
Heavy rain lashed Mumbai today, bringing traffic to a halt.
Commuters waited for hours at flooded local stations.
Street vendors covered their stalls with plastic sheets.
By evening, the city's roads turned into rivers.
Residents say this is the worst monsoon in years.
```
